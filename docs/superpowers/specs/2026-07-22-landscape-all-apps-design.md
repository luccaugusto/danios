# Landscape — Port Remaining Apps: Design

**Date:** 2026-07-22
**Branch:** `landscape-ui` (continues the spike, spec 2026-07-17)
**Status:** Approved

## Goal

Bring the five apps left out of the landscape spike — Calculator, Oracle,
Pet, Pomodoro, Settings — plus the two `main.cpp` stragglers (SD-missing
msgbox, boot splash) to full landscape (320×208 app container) quality,
so the landscape build has no known-broken surfaces. Portrait remains
untouched and both envs keep building (same flag/constants regime as the
spike: `#ifdef` only in `Layout.h`, everything else branches on
`layout::kLandscape` or uses the constants).

## Per-app design

### Calculator — constants only, no branch

- Display label width `240 - 16` → `layout::kAppW - 16`.
- Button matrix size `240 × (288 - kDisplayH)` → `layout::kAppW ×
  (layout::kAppH - kDisplayH)`.
- Portrait values identical; landscape gets a wider, shorter keypad
  (320×152), which suits the 4-column map. Single code path.

### Oracle — no changes (user-verified)

Verified acceptable on device as-is during design review; explicitly out
of scope.

### Pet — landscape two-column Alive screen

Portrait paths untouched (flex already reflows Egg/Memorial/modals).

- **Alive screen (landscape):** root becomes a flex ROW of two columns.
  Left column (~45% width): name label, pet sprite (104×104), mess row,
  health label. Right column (flex column, grow): needs grid
  (ROW_WRAP, rows at `LV_PCT(46)` as today), optional no-clock hint,
  action button row (Alimentar/Brincar/Dar bronca).
  Implementation: split `buildAlive` into left-half/right-half builders
  parented on either the root (portrait, as today) or the two column
  containers (landscape).
- **Food tray modal:** clamp `210×250` to fit — width `min(210, kAppW-8)`,
  height `min(250, kAppH-8)` (→ 210×200 landscape, unchanged portrait).
- Egg and Memorial screens fit 208px as-is (≤ ~190px stacks) — unchanged.

### Pomodoro — landscape two-column

Portrait vertical ladder untouched. Landscape branch:

- **Left column (0..160):** art slot 120×120 (`TOP_MID` x-offset −80,
  y 20); 48pt countdown centered under it (x-offset −80, y ~150).
- **Right column (168..312):** Start/Stop button 144×36 at top (y 16);
  the two duration stepper rows below it (y ~70 and ~120), name labels
  anchored at x 168, the −/value/+ cluster keeping its `TOP_RIGHT`
  offsets (−108/−42/−8), which land inside the right column at 320 wide.
- Flash overlay is `LV_PCT(100)` — unchanged.

### Settings — verification only

Menu list and all section builders are flex + `LV_PCT` throughout; they
reflow at 320×208. No code change; on-device check that section bodies
and the WiFi/location keyboard modals are usable at 208px height.

### main.cpp

- **SD-missing msgbox:** width `230` → `layout::kScreenW - 10` (same
  value portrait, near-full-width landscape).
- **Boot splash logo:** pre-scaled landscape variant generated by the
  weather-art pipeline: `assets/art/boot-logo.png` (240×288) scaled to
  fit the height above the "Conectando" strip — **173×208**, written to
  `sd/art/ls/boot-logo.bin`. Code picks the path with a
  `layout::kLandscape` ternary; `TOP_MID` alignment keeps the 32px
  bottom strip convention in both orientations. Missing-file fallback
  behavior unchanged.

## Assets

One new SD file: `sd/art/ls/boot-logo.bin` (173×208, converted with
`assets/icons/svg_to_lvgl_bin.py --size 173x208`). Committed to the repo
like the weather `ls/` variants; the user copies it to the physical card
(new `ls/` folder directly under `art/`).

## Out of scope

- Oracle (user-verified good).
- New wide-format art (frames, backgrounds) drawn specifically for
  landscape — future work if landscape becomes the default.
- Flipping the default env / removing portrait — that decision comes
  after living with the fully-ported build.
