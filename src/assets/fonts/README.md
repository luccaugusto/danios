# montserrat_pt_14 / montserrat_pt_12

Custom 14px Montserrat LVGL font for danios' Portuguese UI (plus a 12px
variant, `montserrat_pt_12`, used by the launcher grid titles — same ranges,
regenerate with `--size 12` and the matching output name). Extends LVGL's
built-in `lv_font_montserrat_14` ASCII range with Latin-1 accented glyphs
(`0xA0-0xFF`, e.g. ç, õ, ú, Ç) needed for strings like "Configurações",
"Música", "Oráculo", while keeping the same FontAwesome symbol glyphs
(`LV_SYMBOL_LEFT`, `LV_SYMBOL_RIGHT`, etc.) LVGL's built-ins carry, and the
bullet (`0x2022`) `lv_textarea` password mode uses.

Generated by replicating `.pio/libdeps/cyd/lvgl/scripts/built_in_font/built_in_font_gen.py`
(the same script LVGL uses to generate its own built-in fonts) with the
Montserrat range extended from `0x20-0x7F,0xB0,0x2022` to `0x20-0x7F,0xA0-0xFF,0x2022`
(`0xA0-0xFF` already includes the built-in's `0xB0` degree sign), and the
exact same FontAwesome codepoint list.

## Regenerate

Run from `.pio/libdeps/cyd/lvgl/scripts/built_in_font/` (source font paths
are relative to that dir):

```bash
npx --yes lv_font_conv --no-compress --no-prefilter --bpp 4 --size 14 \
  --font Montserrat-Medium.ttf -r 0x20-0x7F,0xA0-0xFF,0x2022 \
  --font FontAwesome5-Solid+Brands+Regular.woff \
  -r 61441,61448,61451,61452,61452,61453,61457,61459,61461,61465,61468,61473,61478,61479,61480,61502,61507,61512,61515,61516,61517,61521,61522,61523,61524,61543,61544,61550,61552,61553,61556,61559,61560,61561,61563,61587,61589,61636,61637,61639,61641,61664,61671,61674,61683,61724,61732,61787,61931,62016,62017,62018,62019,62020,62087,62099,62212,62189,62810,63426,63650 \
  --format lvgl -o /home/lucca/repos/danios/src/assets/fonts/montserrat_pt_14.c \
  --force-fast-kern-format
```

Notes:
- `--no-compress --no-prefilter`: `LV_USE_FONT_COMPRESSED` is `0` in
  `include/lv_conf.h`, so compressed bitmaps aren't supported — same flags
  `built_in_font_gen.py` uses when `--compressed` isn't passed.
- `--force-fast-kern-format`: matches the built-in generator's invocation.
- The C symbol name (`montserrat_pt_14`) is derived by lv_font_conv from the
  output filename's basename.
- The generated file includes `"lvgl.h"` when `LV_LVGL_H_INCLUDE_SIMPLE` is
  defined (set in `platformio.ini`'s `cyd` env `build_flags`) — do not
  hand-edit the generated file's includes.
